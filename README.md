# قالب سوقك الإلكتروني

قالب متجر Flutter عام بواجهة حديثة قابلة لتخصيص الهوية والمنتجات.

## المزايا
- واجهة متجر عربية مع بانر وتصنيفات وبحث.
- شبكة منتجات ومفضلة وتفاصيل المنتج.
- سلة تسوق مع زيادة ونقصان الكميات.
- إجمالي الطلب وتجربة شراء محلية.
- صفحات رئيسية ومفضلة وسلة وحساب.
- بنية Android حديثة مطابقة للمرجع.

## الإصدارات
Flutter 3.47.2، Java 17، Gradle 8.14، Android Gradle Plugin 8.11.1، Kotlin 2.2.20، compileSdk وtargetSdk 36.


## الأيقونة
تم تضمين الأيقونة المربعة داخل `assets/app_icon.png`، ويمكن استخدامها مباشرة كأيقونة التطبيق أو ربطها مع أداة توليد أيقونات المنصات.
